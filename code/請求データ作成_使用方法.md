# 請求データ作成の使用方法



勤務表解析 GUI（`main.py`）における、**請求データ作成**および関連ボタン（請求データ削除・請求ファイル更新）の現行仕様です。



## 概要



解析結果グリッドの各行から、請求用 Excel に書き込むための **更新用列** を自動作成します。実際の Excel 反映は別ボタン「請求ファイル更新」で行います。



| ボタン | 役割 |

|--------|------|

| **請求データ作成** | グリッドに「更新用合計勤務時間（10進）」「更新用交通費合計」を設定 |

| **請求データ削除** | **更新用合計勤務時間（10進）** と **更新用交通費合計** をクリア |

| **画像とデータ照合** | 請求反映前に、画像プレビューと更新用列の値を1件ずつ確認（下記） |

| **請求ファイル更新** | 最終判断「〇」の行を、選択した請求用 Excel に反映 |



## 前提条件



- グリッドに解析結果が表示されていること（新規解析または JSON 読込）。

- **請求ファイル更新** を行う場合は、画面上部の **請求用ファイル**（`.xlsx` / `.xlsm` 等）を参照で指定しておくこと。

- 解析実行そのものには、データフォルダと請求用ファイルの両方の選択が必要（請求データ作成ボタン単体では請求用ファイルは必須ではない）。



## 請求データ作成



### 操作手順



1. 必要に応じてグリッドで行を選択する（未選択の場合は **全行** が対象）。

2. **請求データ作成** をクリックする。

3. 確認ダイアログで OK を押す。



### 対象範囲



- **行を1件以上選択している場合**: 選択行のみ。

- **選択がない場合**: グリッドの全行。



対象行リストに対して `apply_billing_create_for_rows`（`kintai_core.py`）が実行されます。処理開始時に、対象行の更新用列はいったんクリアされます。



### 各行の更新用列（通常は1行1値）



**社員番号が有効な行**について、読取から更新用列を作成します。

**ファイル名の会社名（照合用）と社員番号が同じ行が2件以上**ある場合は、重複解決ダイアログで勤務時間・交通費をそれぞれ「いずれかの行を採用」または「合算」で決めます。各行の **開く** ボタンで、データフォルダ内の元ファイル（画像・PDF・Excel など）を既定アプリで確認できます。結果は **No が最小の行** の更新用列にだけ設定し、その行の **最終判断を「〇」**、同グループの **他行を「✖」** にします（他行の更新用列は空）。候補が全行同一のときはダイアログを省略し、代表行への設定と最終判断の整理のみ行います。



社員番号は次の順で取得します。



1. 行データの `employee_no` / 「社員番号（ファイル名より）」

2. 対象ファイル名から抽出した社員番号（7桁数字、または `BP` + 5桁）



社員番号が有効形式でない行はスキップされます（`^\d{7}$` または `^BP\d{5}$`）。



| 設定する列 | 値の元 |

|------------|--------|

| 更新用合計勤務時間（10進） | その行の「合計勤務時間（10進）」列（`total_hours_decimal`） |

| 更新用交通費合計 | その行の「(読取)交通費合計」列（`transport_expense_raw`） |



**データなし**（`（データなし）` 等）および **数値の 0**（勤務 `0` / `0.00`、交通費 `0`・`0円` など）は、更新用列には **入れず空欄** にします（読取列には `0円` 等を残し、AI読取状態は「ゼロ」のまま）。

**正規化後、更新用の勤務・交通費が両方空**の場合は、その行はスキップされ、更新用列は空のままです（片方だけ非ゼロの値がある行は、もう片方は空欄で設定されます）。



### 完了時の表示



- ステータス欄: `請求データ作成完了（{対象}）: {N} 行に更新用列を設定しました`

- メッセージボックス: 設定した行数



「行数」は、上記ルールで更新用値が1回以上設定された行の件数です。



### ボタン有効条件



- 解析処理中（`_busy`）は無効。

- グリッドに1行以上あるとき有効。



## 請求データ削除



### 操作手順



1. 対象行を選択するか、未選択で全行対象とする（請求データ作成と同じ範囲ルール）。

2. **請求データ削除** をクリックし、確認する。



### 削除される内容



- **更新用合計勤務時間（10進）** と **更新用交通費合計** をクリア（`clear_billing_update_hours_column` → 内部で両列をクリア）。



## 画像とデータ照合（請求前の最終チェック）



**請求ファイル更新** の前に、元ファイルの画像（または **PDF・多ページ TIFF の全ページ** を縦に並べたプレビュー）と、Excel に書き込む **更新用** の勤務時間・交通費を同じ画面で確認できます。請求用 Excel の選択は不要です。

元ファイルが **勤務表などの Excel**（`.xlsx` 等）の場合、アプリ内では印刷レイアウトの見た目を再現できないため Canvas プレビューは行いません。代わりに照合の **前へ / 次へ** でその件を表示したタイミングで **Excel を自動的に開き**、内容は Excel ウィンドウで確認します（**前へ / 次へ** で別件に移るとき、または照合画面を閉じるときに、開いていたブックは可能な範囲で閉じます）。



### 対象行



走査範囲は請求データ作成と同じです（**選択行**、未選択なら **全行**）。そのうち次を満たす行だけを、起動時に一覧化して **1件ずつ** 表示します。



- 最終判断が **「〇」**

- **更新用合計勤務時間（10進）** または **更新用交通費合計** のいずれかが設定されている（合算済マーカー行は除く）



### 操作



- **前へ / 次へ**: 照合リスト内を移動（キー **← / →** も可）。

- **最終判断を ✖ にする**: 現在の行を請求反映対象外にし、グリッドの最終判断を **✖** に更新。リストから外れ、次の行へ進みます。

- **ファイルを開く**: データフォルダ内の元ファイルを既定アプリで開く（Excel は表示時に自動オープンされますが、再度開く場合などに使用）。重複解決で複数行が同じ会社名＋社員番号のグループになっている場合は、**グループ内の全行のファイル**を順に開きます。

- **更新用列の編集**: 右側の **更新用合計勤務時間（10進）** と **更新用交通費合計** はテキストボックスで編集できます（空欄は Excel では空セル。0 相当は空に正規化されます）。

- **グリッド更新**: 編集内容をメイン画面のグリッド（代表行の更新用列）に反映します。請求用 Excel への書き込みは **請求ファイル更新** の操作が別途必要です。

- **未反映の編集**: **グリッド更新** せずに **前へ / 次へ / 閉じる** すると、未反映の変更がある場合に確認ダイアログが出ます（破棄して続行するか、キャンセルして編集を続けるか）。

- **プレビューのスクロール・拡大**: 左のプレビュー枠では **マウスホイール** で縦スクロール、**Shift + ホイール** で横スクロール、**Ctrl + ホイール** で拡大・縮小できます（スクロールバーでも操作可能）。照合行を切り替えると拡大率は初期に戻ります。


### プレビュー（重複グループ）



請求データ作成で **会社名（ファイル名）と社員番号が同じ複数行** を合算・代表行にまとめた場合、照合リストは代表行（最終判断「〇」）1件ですが、プレビューには **メイングリッド全行** からそのグループに属するファイルを集め、**No 昇順で左から横に並べて** 表示します（各枠は **独立して縦横スクロール**・**Ctrl + ホイールで拡大縮小**）。1ファイルの PDF で複数ページある場合は、その枠の中でページを縦に並べます。合算後の更新用の値は代表行の1セットのみ表示されますが、元資料は行ごとに確認できます。グリッドで代表行だけを選択して照合を開いても、同グループの他行のファイルがプレビューに含まれます。



照合リストに載る各行の更新用値は起動時にグリッドから読み込みます。**グリッド更新** 後はその行のスナップショットも更新され、メイングリッドと一致します。



## 請求ファイル更新（請求データ作成後の流れ）



請求データ作成だけでは Excel は変更されません。反映には **請求ファイル更新** を使います。



### 操作手順



1. 必要に応じてグリッドで行を選択する（未選択の場合は **全行** が走査対象）。

2. **請求ファイル更新** をクリックし、確認する。

3. 処理完了後、**結果** ダイアログで成功・失敗・スキップ件数を確認する。成功（「〇」）以外の行は **No・ファイル名・結果** の一覧で表示され、件数が多い場合はスクロールバーとマウスホイールで閲覧できる（全件成功のときは一覧は空）。



### 走査範囲（グリッド）



請求データ作成・請求データ削除と同じです。



- **行を1件以上選択している場合**: 選択行のみ。

- **選択がない場合**: グリッドの全行。



上記の範囲のうち、次を **すべて**満たす行だけ Excel に反映します。



| 条件 | 内容 |

|------|------|

| 最終判断 | 「〇」 |

| 更新用合計勤務時間（10進） | 値があり、旧仕様の合算済マーカー **ではない**（レガシー互換） |



条件を満たさなかった行や、走査範囲外の行は **請求用ファイル更新** 結果列は更新しません。



旧仕様で残っている `No.XXのレコードに合算済` は更新対象外です。**請求データ作成** を再実行すると通常の値に置き換わります。



### 請求用 Excel の更新先



- シート名: **エンジニアTS一覧**

- 行の特定: 対象ファイル名から **取引先名（末尾の「様」を除去）** と氏名を解析し、シートの **D列（取引先名）・E列（氏名）** と照合した **行のみ** H列・O列を更新する（A列社員番号だけでは全行更新しない）。

- 同一社員番号・同一取引先で複数行ある場合は、**ファイル名の氏名と E 列が一致する行**のみ更新する。



| Excel 列 | 内容 | グリッドの元 |

|----------|------|----------------|

| H列 | 通常請求時間 | 更新用合計勤務時間（10進） |

| O列 | 旅費交通費請求金額 | 更新用交通費合計 |



交通費・勤務時間の扱い（H列・O列）:

- 更新用列が **空欄**（データなし・0 相当を含む）→ Excel のセルを **空** にする（数値 `0` も書き込まない）。
- 更新用列に **0 以外の数値** がある行のみ、その値を書き込む。

**請求データ作成** 実行時、読取が（データなし）または 0・0円 などの場合は、対応する更新用列も空欄になります。



### 既存値がある場合の上書き確認



対象 Excel 行の **通常請求時間（H）・旅費交通費（O）が両方空** のときは、確認なしで両方に新値を書き込みます。

**どちらか一方または両方**に既存値（セルが空でない。数値 `0` も既存あり）があるときは、上書き確認ダイアログを表示します。

| 表示 | 内容 |
|------|------|
| 通常請求時間（現在） / （更新後） | Excel の現値と、グリッドから書き込む値（空は `（空）`） |
| 旅費交通費（現在） / （更新後） | 同上。更新後が空セルにする場合は **（空）** と表示 |
| 勤務時間を上書き / 交通費を上書き | 列ごとのチェック。OFF の列は Excel を変更しない（既存の交通費を空にする場合も、このチェックで実行可否を選べます） |

キャンセルした場合は Excel は保存されません。両方のチェックを OFF にして実行した行は **スキップ** となります。



### 同一社員番号の複数グリッド行について（運用注意）



**請求データ作成**で会社名＋社員番号の重複を解決した場合、請求に載せる更新用値と「〇」は **No 最小の代表行のみ** です。請求ファイル更新は最終判断「〇」の行だけが Excel に反映されるため、代表行が主になります。

社員番号だけが重複（会社名キーは異なる）した行は、従来どおり行ごとに更新用が付きます。グリッドの社員番号重複は赤字表示のままです。



### 請求用ファイル更新の結果列



グリッドの **請求用ファイル更新** 列に次のいずれかが入ります。



| 表示 | 意味 |

|------|------|

| 〇 | シートへの書き込み成功（1列以上を更新） |

| スキップ | 上書き確認で勤務時間・交通費の両方のチェックが OFF |

| ✖ | 書き込み失敗、旧合算済マーカー行、勤務時間不正、交通費不正など |

| （対象レコードなし） | ファイル名と請求シートの D/E 列照合で一致行がない |



## 推奨ワークフロー



```mermaid

flowchart LR

  analyze[新規解析またはJSON読込]

  judge[最終判断を確認・修正]

  create[請求データ作成]

  update[請求ファイル更新]

  analyze --> judge --> create --> update

```



1. データフォルダ・請求用ファイルを指定し、解析を実行する。

2. 会社名・氏名・勤務時間・種別照合などを確認し、**最終判断** を必要に応じて編集する。

3. **請求データ作成** で各行の更新用列を作る。

4. 請求用ファイルを指定し、**請求ファイル更新** で Excel に反映する。

## 補足



- グリッドの JSON 保存・読込時、請求用ファイルのパスは `billing_file_path`（または `billing_file`）として保存されます。
